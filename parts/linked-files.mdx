When you import OBJ, STL, FBX, or 3MF models, choose whether the costume stores the model or links to its original file. These choices appear after file selection in **Model Import**.

## Choose how to save your models

| Option | How it works | When to use it |
| --- | --- | --- |
| **Include in costume** | Saves the model inside the costume. Selected by default. | Sharing, backups, or working without the original source. |
| **Link to original file** | Keeps a saved level-of-detail model for loading; full detail comes from the original file. | A stable model library where you can keep the source available. |

Your costume still saves fitting and workspace work. Linked storage does not make the source application and Armorsmith synchronize edits automatically. Geometry that cannot be reproduced from its source, including unsupported skinned or processed geometry, may need to remain included.

## Link a model during import

1. Choose **File → Import** and select an OBJ, STL, FBX, or 3MF.
2. In **Model Import**, choose **Link to original file**.
3. Leave **Review orientation and size before import** checked and click **Next: Review Import**, or clear it and click **Import**.
4. Complete the [model import procedure](/parts/importing-models), then save your costume.

Use **Show File Storage Details** for the dialog's explanation. Linked source files larger than 2 GB cannot be bundled by the current implementation; choose **Include in costume** for those files.

## Keep the accepted import size

Accepted orientation and sizing are saved with a supported linked source and replayed when its full geometry is loaded. Do not apply the same import scale a second time. Check a known dimension after saving and reopening.

Linked storage does not replace a changed source automatically. For a deliberate geometry replacement, use [Re-import Model](/parts/importing-models#replace-a-fitted-model) and inspect the retained fit.

## Find a moved or missing source file

Keep the original source file unchanged and available. If a required linked file cannot be loaded, **Linked file unavailable** offers:

- **Locate File…**: select the expected source at its new location.
- **Search Folder…**: search the chosen folder and its subfolders for a matching file.
- **Cancel**: stop loading the costume.

Armorsmith checks the file's contents. An edited version cannot silently replace the geometry used by your saved fitting work. Restore an unchanged source to reopen the costume, then import a changed model separately for comparison. Save after reconnecting a moved file.

## Share a costume without separate source files

Choose **File → Publish Costume** and save a separate published `.costume` file. Publishing bundles the required source files for sharing; your working costume stays open. Keep using **Save** to preserve its edits.

See [costume files](/interface/costume-files) for editable folders, published bundles, and legacy `.armor` files. A published costume in this build does not include a mobile-viewer scene.
