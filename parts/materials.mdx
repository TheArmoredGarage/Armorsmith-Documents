<Info>
These instructions are for **Armorsmith Designer 2.1.1.0**. Earlier versions, including 2.1.0.10, can show different panels and labels.
</Info>

Use contrasting colors to distinguish costume pieces while fitting them. An appearance setting helps you read the design; it does not choose physical foam, paint, or fabric for you.

## Change a selected part

1. Select the intended attachment in Costume or Browse → Attachments.
2. Open **Workbench → Inspect** and check the selected name.
3. Use the available color, opacity, and texture-visibility controls for that target.
4. Inspect the result from several angles and save the costume.

Available controls depend on the selected object. Do not assume a generic shader/material editor is available for every part.

## Color a foam assembly

Use **Preview Color** in [Edit Foam](/foam-preview/layers-and-materials#set-preview-colors-and-shared-values) for a base or raised piece. Layer-wide color actions and individual overrides have different scopes; check the selected row before applying.

## Check output separately

Colors, textures, and print display options serve different purposes. Inspect the actual pattern/output settings before assuming a viewport appearance will print. Record the real material and finish in construction notes, and save/reopen a test copy before a handoff.
