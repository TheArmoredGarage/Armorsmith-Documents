Import a model into a workspace before attaching it to your avatar. A workspace holds the source model and its pattern work; importing does not automatically fit or attach the model.

## Before you import

Save your costume. Keep the source model and any companion material or texture files together. Know a real dimension of the part so you can check its size after importing.

Use **File → Import** for costume parts. Use [**Avatar → Custom Mesh → Import**](/avatar/custom-avatars) for a body model, or [**Add Animation**](/avatar/posing#import-an-animation) for an animation clip.

## Supported file formats

| Format | What to expect |
| --- | --- |
| **OBJ** | Mesh geometry; keep its companion MTL and texture files available. |
| **STL** | Mesh geometry without color or texture information. Check size because the file does not identify its measurement units. |
| **3MF** | Model geometry, declared units, assembly transforms, and supported colors. A file can contain several models. |
| **FBX** | Model geometry and supported scene/material information. Importing a costume model is separate from importing a rigged avatar or animation. |
| **PDO** | A Pepakura model and its pattern data. Uses its existing import workflow rather than the new model storage/orientation dialog. |
| **ADO** | An Armorsmith part file. Uses its existing part import workflow. |

## Importing a model

1. Choose **File → Import**. In **Import a Model/PDO**, select your file and click **Open**. You can select several files at once.
2. For OBJ, STL, 3MF, or FBX, the **Model import** dialog opens. Under **Store the source file**, choose:
   - **Include in costume**: the default; saves the model inside the costume.
   - **Link to original file**: keeps the original file as the full-detail source. Keep that file available at its saved location. See [linked model files](/parts/linked-files).
3. Leave **Review orientation before import** checked to preview alignment. Click **Next: Review orientation**. To keep the source orientation without reviewing it, clear the checkbox and click **Import**.
4. If you selected several model files, answer the **Multiple Imports** question. Choose **Yes** and enter a group name to preserve an assembly as a group, or **No** to import independently. This group choice is not offered when the selection contains PDO or ADO files. Group imports skip orientation review to preserve assembly layout.
5. If a 3MF contains several models, choose how to organize them as described below.
6. Complete any orientation review, then wait for loading to finish. Find the imported workspace or workspaces in the [Workspaces Panel](/interface/workspaces-panel).
7. Inspect the model from several angles. Use [Measure](/interface/measurement-tool) to compare a known dimension. Correct size or orientation before [attaching the workspace](/parts/attaching-parts).

Opening an OBJ, STL, FBX, or 3MF from **File → Recent Imports** also asks for the model storage and orientation choices.

## Review orientation

The **Review orientation** dialog compares **Before** and **After** previews. Use **View: Front**, **Side**, and **Top** to check that the part is upright and faces the intended direction.

1. Inspect the suggested alignment. A suggestion can keep the original orientation when no reliable correction is found.
2. Open **Adjust orientation** if you need a different result. Choose an **Automatic alignment** option, use **Reapply suggestion**, enter X/Y/Z rotations in degrees, or use a **Flip** button for a 180-degree turn.
3. Use **Reset to original** to discard the adjustments in the preview.
4. Click **Import with orientation** to accept the preview, or **Import original** to keep the source orientation.

Alignment changes orientation, not the part's intended physical size. Check its dimensions separately. If no usable surface is available for review, inspect the loaded model directly.

## Import several models from a 3MF

In **Import 3MF Models**, choose one of these options:

| Option | Use it when |
| --- | --- |
| **Separate Workspaces** | You want to manage and attach the models independently. This is the default choice. |
| **Merge into One Workspace** | You want the models together in one workspace. |
| **Cancel** | You want to stop this 3MF import. |

For example, choose **Separate Workspaces** for a helmet and separate cheek pieces you plan to fit individually. Choose **Merge into One Workspace** when you want to manage the assembly together. This choice concerns models inside one 3MF; the **Multiple Imports** group question concerns several selected files.

The importer converts declared 3MF units to the application's internal millimetres and reads supported model/component transforms. It is a model importer: do not assume slicer settings, supports, printer profiles, or every 3MF extension will transfer.

## Troubleshoot an import

| Symptom | What to check |
| --- | --- |
| The part is too large or small | Compare a known dimension with Measure. Check source units, then use Scale or correct the source model. |
| The model faces the wrong direction | Use orientation review, or Rotate after loading. Check front and side views before attaching it. |
| **3MF Import Error** appears | Read the specific error. Unsupported required extensions, invalid assemblies, or missing material resources can prevent import. Try a model-only 3MF or export OBJ/STL from the source application. |
| A linked file cannot be bundled | The current implementation rejects linked source files larger than 2 GB. Import with **Include in costume** instead. |
| A linked costume cannot find its model later | Restore the expected original file or follow [missing-source recovery](/parts/linked-files#find-a-moved-or-missing-source-file). |

Save your costume after importing and fitting. For a single-file handoff, use [Publish Costume](/interface/costume-files#publish-one-file-for-sharing).
