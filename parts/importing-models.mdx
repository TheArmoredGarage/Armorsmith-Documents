Import a costume model into a workspace before attaching it to your avatar. Importing does not automatically fit or attach the part.

## Before you import

Save your costume. Keep the source model and its companion materials and textures together. Know a real dimension of the piece so you can check its size.

Use **File → Import** for costume parts. Use [Avatar → Custom Mesh → Import](/avatar/custom-avatars) for a body model and [Add Animation](/avatar/posing#import-an-animation) for a compatible rig's animation clip.

## Supported formats

| Format | What to expect |
| --- | --- |
| **OBJ** | Mesh geometry; keep MTL and texture files available. |
| **STL** | Geometry without color or texture information. Check size because STL does not identify its units. |
| **3MF** | Supported model geometry, declared units, assembly transforms, and colors. One file can hold multiple models. |
| **FBX** | Supported geometry and scene/material information. Costume-part import is separate from body or animation import. |
| **PDO** | Pepakura model and pattern data, using its own import workflow. |
| **ADO** | Armorsmith part data, using its own import workflow. |

## Import a model

1. Choose **File → Import** and select the source file. You can select several files together.
2. For OBJ, STL, 3MF, or FBX, review **Model Import**. Leave **Include in costume** selected to store the model with the costume, or choose **Link to original file** if the original will remain available. See [linked sources](/parts/linked-files).
3. Leave **Review orientation and size before import** checked and click **Next: Review Import**. To skip review and keep the source setup, clear it and click **Import**.
4. Complete any grouping or 3MF organization choices below.
5. Complete orientation/size review when offered, then wait for loading.
6. Find the workspace under **Workbench → Browse → Workspaces**. Inspect and measure it before attaching it.

PDO and ADO do not use the new storage/review dialog. Recent Imports also offers the applicable model storage/review choices.

## Review orientation and size

**Review Orientation And Size** compares Before and After. Use Front, Side, and Top views to check the direction and proportions.

1. Check the suggested alignment. An uncertain suggestion can keep the original direction.
2. Set **Longest Side** in **millimetres** if you know the required largest dimension. All dimensions scale together. Read the resulting X/Y/Z dimensions and percentage before accepting.
3. Use **Reset Size** to discard sizing changes.
4. Open **Adjust Orientation** for automatic-axis choices, X/Y/Z angles, or the axis **Rotate … (90 deg)** controls. Use **Reapply Suggestion** or **Reset To Original** when needed.
5. Click **Import Adjusted** when you have changed size, or **Import With Orientation** for an orientation-only correction. **Import Original** keeps the original setup instead of accepting the review adjustments.

Sizing is still available when automatic orientation is uncertain. For example, if a practice bracer's largest dimension is 100 mm and you enter 200 mm, its other dimensions scale by the same factor. This is uniform sizing, not a local fit adjustment.

After importing, use [Measure](/interface/measurement-tool) to verify a known dimension. Review sizing is baked into imported geometry, so it does not need to appear as a non-neutral workspace scale. Continue with [attaching and fitting](/parts/attaching-parts).

## Organize multiple imports

For several selected model files, **Multiple Imports** can ask whether to import as a group. Choose Yes and name the assembly to preserve its relative layout, or No for independent imports. Group imports skip orientation/size review to preserve that assembly. A selection containing PDO or ADO does not offer this grouping question.

For multiple models inside one 3MF, **Import 3MF Models** offers **Separate Workspaces**, **Merge into One Workspace**, or **Cancel**. Keep helmet cheek pieces separate when they need individual fitting. This choice concerns models inside one file, not the group question for several selected files.

3MF transfers supported model data. Do not assume slicer profiles, supports, printer settings, or every extension will transfer.

## Replace a fitted model

Use replacement when the source geometry has changed and you need to inspect it with the existing fitted placement. Save a copy first.

1. Select the fitted attachment in Costume.
2. Right-click it and choose **Re-import Model**.
3. Choose a replacement **PDO**, **OBJ**, or **STL**. This command has a narrower filter than initial import.
4. Inspect the replacement, linked mirrors, placement, dimensions, and pattern work before saving the new version.

Replacement stages the new geometry before changing the fitted model. If loading fails, the original is kept. Retained placement is not a promise that arbitrary topology changes preserve every downstream edit; compare the result carefully.

## Troubleshoot import

| Symptom | Next check |
| --- | --- |
| The piece is too large or small | Check the known dimension and units. Use review sizing during import or the attached part's Scale tool. |
| The model faces the wrong way | Review orientation from several views; use the axis rotation controls or Rotate after import. |
| A recent import is missing or unreadable | Restore the file or select it at its new location through File → Import. |
| 3MF Import Error appears | Read the specific error. Try a model-only file or an OBJ/STL export when required data is unsupported. |
| A linked source cannot be bundled | The current bundling implementation rejects linked sources larger than 2 GB. Use Include in costume instead. |
| A saved linked costume needs its source | Follow [missing-source recovery](/parts/linked-files#find-a-moved-or-missing-source-file). |

Save after fitting. For a single-file handoff use [Publish Costume](/interface/costume-files#publish-one-file-for-sharing).
