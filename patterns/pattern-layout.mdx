<Info>
These instructions are for **Armorsmith Designer 2.1.1.0**. Earlier versions, including 2.1.0.10, can show different panels and labels.
</Info>

Use the pattern viewport to edit unfolded pieces and arrange them on the pages. The toolbar above the 2D view contains pattern editing tools. The vertical **Pattern Layout** toolbar along its left edge contains alignment, distribution, and orientation controls.

<Note>
The **Unfold** button starts an automatic unfold. Islands follow a separate workflow: their patterns update dynamically as you edit the islands in the 3D view. See [Create and manage islands](/patterns/create-and-manage-islands).
</Note>

## Pattern toolbar

| Tool | What it does |
| --- | --- |
| **Transform** | Moves or rotates the selected pattern in the 2D layout. |
| **Join/Cut** | Joins pattern edges or cuts a connection to separate pieces. |
| **Measurement Tool** | Measures in the pattern view. |
| **Edit Shape** | Opens contextual Vertex, Segment, and Spline editing in Workbench Edit for a supported selected outline. |
| **Grid** | Shows or hides the grid in the pattern view. |
| **3D Panel** | Shows or hides the 3D view on the left, giving the pattern view more room. |
| **Print** | Opens the printing workflow. |
| **Repack Unfold** | Arranges pattern pieces in the layout automatically. |
| **Unfold / UndoUnfold** | Opens the automatic unfold threshold dialog, or undoes the model unfold. |

Hover over an icon to identify it. **Transform** has tooltip **Transform Tool**; **Repack Unfold** has tooltip **Re-calculate the layout of the pattern parts**.

## Create and edit a drawing

Open **Create** above the pattern view for **Line**, **Rectangle**, **Circle**, **Text**, and **Image**. This menu replaces the separate Create 2D dock. Organize the result in [Browse → Patterns](/patterns/layers-and-groups), and check Drawing Into before creating more items.

Select an outline and open **Edit Shape**. Choose Vertex for anchors/corners, Segment for sections between anchors, or Spline for the whole outline. Available tools depend on that level. Use Done when finished. For closed foam cut outlines, see [drawing and promotion](/foam-preview/drawing-and-editing).

## Reuse an outline

Right-click a supported outline for **Create Instance**, **Create Mirrored Instance**, **Copy**, and **Paste**. Instances link outline edits while keeping independent placement. Use **Make Unique** before changing only one copy's outline. **Enable Live Symmetry** and **Bake Symmetric Outline** control a symmetric construction relationship, rather than mirroring an attachment on the avatar.

## Accept or cancel an unfold

The Unfold editor uses **Apply** and **Cancel** in Workbench Edit. Check its settings before applying; Cancel leaves the model and unfold settings unchanged. Use UndoUnfold to return from an applied automatic unfold.

## Move or rotate a pattern

Select a pattern in the 2D view to work with it. The selected pattern is outlined and shows transform handles.

<Frame>
  ![A selected pattern with its move and rotation handles](/images/edit-patterns-toolbar.png)
</Frame>

1. Select **Transform**, then click the pattern you want to change.
2. Click and drag the pattern to move it.
3. To rotate it, click the small circular handle above the selection and drag.

For a 90° turn, use the [orientation controls](#rotate-pattern-orientation) on the vertical toolbar.

<Tip>
Hide the 3D panel when you want more room for arranging patterns. Turn it back on to compare a piece with its position on the model.
</Tip>

## Align selected patterns

Alignment lines up two or more selected pieces using their combined bounds. It moves the pieces without changing their size or orientation.

1. Select **Transform** and click a piece.
2. Hold **Ctrl** and click additional pieces to add them to the selection.
3. Click an alignment button on the vertical **Pattern Layout** toolbar.

The first six buttons appear in this order from top to bottom:

| Tool | What it does |
| --- | --- |
| **Align left** | Lines up the left edges of the pieces' bounds with the leftmost edge of the selection. |
| **Align horizontal centers** | Lines up the pieces' horizontal centers with the horizontal center of the selection. |
| **Align right** | Lines up the right edges of the pieces' bounds with the rightmost edge of the selection. |
| **Align top** | Lines up the top edges of the pieces' bounds with the topmost edge of the selection. |
| **Align vertical centers** | Lines up the pieces' vertical centers with the vertical center of the selection. |
| **Align bottom** | Lines up the bottom edges of the pieces' bounds with the bottommost edge of the selection. |

<Note>
Alignment uses the bounds of the selected pieces, rather than the page margins. It can leave pieces overlapping. Use the distribution controls to space them out.
</Note>

## Distribute selected patterns

The two buttons below the alignment controls arrange two or more selected pieces with a consistent gap between their bounds.

| Tool | What it does |
| --- | --- |
| **Distribute horizontally** | Arranges pieces side by side, preserving their left-to-right order and aligning their vertical centers. |
| **Distribute vertically** | Arranges pieces in a column, preserving their top-to-bottom order and aligning their horizontal centers. |

Select the pieces, then click the distribution button for the arrangement you want. Check the result against the page boundaries and move the arranged pieces if needed.

## Rotate pattern orientation

The two buttons at the bottom of the vertical toolbar turn each selected pattern by 90°.

| Tool | What it does |
| --- | --- |
| **Rotate left** | Turns each selected pattern 90° to the left (counterclockwise). |
| **Rotate right** | Turns each selected pattern 90° to the right (clockwise). |

Select one pattern, or hold **Ctrl** to select several, then click the rotation button. Each click applies another 90° turn. Use these controls to change a piece's orientation before aligning or distributing the layout. For other angles, drag the rotation handle with **Transform**.

## Change how pieces connect

Select **Join/Cut** to work with connections between pattern pieces. Cut a connection when you need separate pieces; join edges when you want pieces connected in the flat pattern. Inspect the result in the 2D view before arranging the pieces.

## Arrange and check the layout

Use **Repack Unfold** to arrange pieces automatically, then refine the layout with the alignment, distribution, and rotation controls. Use **Transform** to adjust individual pieces. Turn on the **Grid** when it helps you position the layout. Use the **Measurement Tool** to check sizes before printing.

Check for overlapping pieces and pieces crossing page boundaries after changing the layout. If you run **Repack Unfold** again, it recalculates the arrangement.

When the layout is ready, select **Print**. See [Printing](/patterns/printing) for page and print settings.
