Open **View → Workshop** to work with the model and its flat patterns. Earlier guides call this area Pattern or Patterns. For an editable low-polygon model, Workshop places the 3D model beside its printable patterns; the 2D area can remain hidden for a dense source without pattern content. Use the model view to see where pieces come from, then work with the pieces and pages in the pattern view.

## Find your way around

| Area | What you'll find there |
| --- | --- |
| **3D model view** | The model and the island tools above it. Select an island to work on a particular area of the model. |
| **Pattern viewport** | The unfolded pieces arranged on pages, with rulers along the top and left. The toolbar above the view contains pattern editing tools. |
| **Pattern layout toolbar** | The vertical toolbar along the left edge of the pattern viewport. Use it to align selected pieces, distribute them in rows or columns, and rotate their orientation by 90°. |
| **Workspaces** | Your model workspaces and their import, creation, deletion, and attachment controls. |
| **Property Grid** | Settings for the selected workspace, including pattern display and appearance options. |
| **Transforms** | Position, rotation, and scale fields for a selected item when those controls are available. |

## Show the details you need

Select a workspace and expand **Display** in the Property Grid. You can choose whether the pattern view shows edge angles, edge IDs, page numbers, registration marks, fold lines, tabs, and textures.

<Tip>
If the page looks busy, hide the details you don't need while arranging pieces. Turn them back on when checking the layout before printing.
</Tip>

For a complete first exercise, follow [Prepare a fitted piece for pattern layout](/getting-started/first-pattern-layout).

## A typical workflow

1. Choose the workspace containing the model you want to work on.
2. Create islands on the 3D model to define areas you want to work with.
3. Watch the island patterns update in the pattern view as you edit the islands.
4. Inspect and arrange the pattern pieces on the pages. Use the layout toolbar to align, distribute, or rotate selected pieces.
5. Check the display and print settings before printing.

See [Edit patterns](/patterns/pattern-layout) for the pattern editing and layout tools. See [Create and manage islands](/patterns/create-and-manage-islands) for the tools above the 3D view.
