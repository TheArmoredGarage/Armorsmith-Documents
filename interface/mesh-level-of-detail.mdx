Automatic **level of detail (LOD)** creates a simplified display mesh for dense models. Armorsmith uses that mesh at every zoom level to reduce viewport drawing work. Zooming in does not switch to full resolution.

You can show the working mesh with **Toggle Full Resolution** in the Costume toolbar. You do not need to run **Decimate** to create a display LOD.

## Which meshes get LOD?

A working mesh with **more than 100,000 triangles** qualifies for automatic simplification. Armorsmith creates **one display version targeting 100,000 triangles per mesh**. A mesh with exactly 100,000 triangles or fewer normally keeps its working detail.

For example, a 1,000,000-triangle mesh can have its full working geometry and a separate display mesh targeting 100,000 triangles. There is no additional 25,000-triangle display level.

<Note>
The triangle count is a target, not a guarantee. The simplified result can remain above it. If Armorsmith cannot create a usable display mesh, it keeps drawing the working mesh.
</Note>

## When does each level appear?

Once a display LOD is ready, Armorsmith normally uses it at every distance and zoom, including in orthographic views. Before it is ready, you see the working mesh. A saved costume can also open directly using its saved LOD.

**Wireframe** follows the displayed geometry too. Turning on wireframe alone does not show the full working topology.

### Show full resolution

1. In the Costume toolbar, find the **eye icon** beside **Toggle Environment**. Its tooltip says, "Click to show every model at full resolution instead of its simplified display version".
2. Click **Toggle Full Resolution** to turn it on. Armorsmith displays the full working meshes. If a model opened using a saved LOD, Armorsmith loads its full geometry first.
3. Inspect the model, or use **Wireframe** to inspect its working topology.
4. Click **Toggle Full Resolution** again to return to simplified display where an LOD is available.

The toggle applies across models, rather than only to the selected part. Showing full resolution can make dense costumes slower to draw. Armorsmith continues preparing display LODs while full resolution is enabled.

## What happens while you edit?

Armorsmith generates display LODs in the background. Posing, animation, bone changes, and **Free Form Deformation (FFD)** update the existing display mesh to follow the model instead of starting simplification again for every movement. Some FFD previews use the working mesh while you drag.

Changes to topology, such as **Decimate** or undoing it, require a replacement LOD. After a topology change, Armorsmith normally waits about 300 milliseconds before starting simplification. It draws the working mesh until a replacement is ready. Initial preparation can start immediately.

Material changes also appear on the display LOD.

### Fitting uses simplified geometry too

**Fit Checker** and **Shrink Fit** use the fitting mesh, which is the LOD when available. Their results are approximate: small local intersections can remain. Inspect the fit colors and check important clearances yourself.

**Toggle Full Resolution** changes viewport display. It does not force these fitting tools to use the full mesh.

## Does LOD change printing or export?

Viewing a simplified mesh does not replace the working geometry. Mesh export and pattern operations that require full geometry use the working mesh, including any **Decimate** result you have applied. They can load full geometry first when the costume opened from a saved LOD.

For example, displaying a million-triangle working mesh through its LOD does not make its mesh export a 100,000-triangle mesh. Display LOD also does not make a dense model suitable for every pattern-editing workflow.

### Saved costumes and loading detail

The `.costume` format can store an LOD alongside the model's full geometry or its linked source reference. When a compatible saved LOD is available, Armorsmith can open the model using that representation and defer loading full detail until an operation needs it. Saving can include a step to prepare the LOD.

An operation that needs full detail can show **Loading the full-resolution model...** while the viewport continues displaying the LOD. If you cancel the wait, that operation stops, but loading can finish in the background. With full resolution enabled, models switch to full detail as it becomes available.

For linked models, keep the original source file available and unchanged. See [linked model files](/parts/linked-files) and [costume files](/interface/costume-files#linked-models-and-loading-detail).

## How is this different from Decimate?

**Decimate** intentionally changes the working mesh. Its result can affect editing, unfolding, and export. Automatic LOD keeps a separate simplified representation for display and fitting.

Armorsmith chooses its working geometry in this order:

1. Your **Decimate** result, if one exists.
2. The evaluated mesh with its pose or FFD applied, if one exists.
3. The original loaded mesh.

LOD follows whichever working mesh is active. Changing the original pose or FFD after decimation does not silently regenerate your Decimate result.
