Use the Costume viewport to inspect your avatar, position costume parts, and check how they fit together. The toolbar above the viewport provides editing and animation tools.

  ![The Costume viewport and its toolbar](/images/CostumeViewport.png)
</Frame>

## Navigate the 3D view

Move the pointer inside the viewport before using the mouse controls.

| Action | Input | Result |
| --- | --- | --- |
| **Rotate view** | Right-click and drag | Orbit around the current pivot. |
| **Pan view** | Middle-click and drag | Move the view without changing its angle. |
| **Zoom** | Scroll wheel | Zoom toward or away from the pointer. |
| **Select object** | Left-click | Select a part and show its properties. Click empty space to deselect. |
| **Frame selection** | **Z** | Center the selected object in the view. |
| **Frame all** | **Shift+Z** | Fit the avatar and attached parts in the view. |
| **Front view** | **F** | Face the scene from the front. |
| **Side view** | **L** | Face the scene from the side. |
| **Perspective / orthographic** | **P** | Switch between depth perspective and a flat projection. |

<Tip>
If you lose track of the model while panning or zooming, press **Shift+Z** to frame the whole scene.
</Tip>

## Mirror selected attachments

In builds with the updated mirror command, select one or more attached parts, focus the **Costume viewport**, and press **Shift+M** to toggle their linked mirrors. **Ctrl+Z** undoes the whole mirror action, and **Ctrl+Y** redoes it. **M** activates **Measure**.

See [Attachments](/parts/attaching-parts#mirror-an-attached-part) for attachment properties, paired parts, and mirroring several selected parts.

## Dense meshes and display detail

The upcoming [automatic mesh LOD system](/interface/mesh-level-of-detail) uses reduced display versions for meshes above 100,000 triangles as you zoom out. Editing, printing, and export retain the working geometry.

## Costume toolbar

The toolbar groups file actions, avatar modes, and tools for editing selected parts.

### File and avatar controls

| Button | What it does |
| --- | --- |
| **Open** | Open a costume file. |
| **Save** | Save the current costume. |
| **Edit Avatar** | Enter or leave avatar editing mode and show the avatar editing panel. |
| **Edit Pose** | Enter or leave pose editing mode. |
| **Fit Checker** | Show a heatmap of the distance between costume parts and the avatar to help you check fit. |

### Part editing tools

| Button | What it does |
| --- | --- |
| [**Translate**](/interface/translate-tool) | Move selected objects in the work area. |
| [**Rotate**](/interface/rotate-tool) | Turn selected objects. To adjust their size, see [uniform and non-uniform scaling](/interface/scale-tool). |
| [**Scale**](/interface/scale-tool) | Resize selected objects uniformly or along individual axes. |
| **Measure** | Measure between points in the work area. |
| [**Free Form Deformation (FFD)**](/interface/ffd-tool) | Deform a selected object with a lattice cage. |

For exact position, rotation, or scale values, use the [Transform Panel](/interface/transform-panel).

### Animation controls

| Control | What it does |
| --- | --- |
| **Animation Selector** | Choose an animation to preview on the avatar. |
| **Play / Pause** | Play or pause the selected animation. |
| **Stop** | Stop the animation. |
| **Animation Scrubber** | Pause the animation, then drag the scrubber to inspect a particular moment. |

<Tip>
Rotate around a positioned part to check its fit from several angles. A part that looks clear from the front may intersect the avatar from the side.
</Tip>
