<Info>
These instructions describe the upcoming **Armorsmith Designer 2.1.1.0** interface. The public 2.1.0.10 release can show different panels and labels.
</Info>

The menu bar runs across the top of the Armorsmith Designer window. Use it to manage files, edit your avatar and costume parts, arrange panels, and find help. The tables group commands by purpose; availability depends on the selected object and view.

## File menu

Use **File** to create, open, save, import, and export costume files and patterns.

| Command | What it does |
| --- | --- |
| **New** | Create an empty costume. You are prompted to save unsaved changes before it opens. |
| **Open** | Choose an existing costume file from your computer. The file picker shows supported costume formats. |
| **Recent Costumes** | Open a submenu of recently loaded costume files. |
| **Merge** | Merge an existing costume file with the costume you have open. |
| **Save** | Save to the current file location. For a costume you have never saved, this opens **Save As**. Shortcut: **Ctrl+S**. |
| **Save As** | Save the costume with a new name or in a new location. Shortcut: **Ctrl+Shift+S**. |
| [**Publish Costume**](/interface/costume-files#publish-one-file-for-sharing) | Package the current costume into one `.costume` file for sharing, including required linked sources. Your working costume stays open. |
| **New Workspace** | Create a blank workspace for making templates with the 2D spline tools. |
| [**Import**](/parts/importing-models) | Import a model into a workspace. For OBJ/STL/3MF/FBX, choose storage and review orientation and size before attaching it to the avatar. |
| **Recent Imports** | Open a submenu of recently imported files. |
| **Search Online** | Open a search window for Armorsmith's online repository of files. |
| [**Export**](/patterns/export-formats) | Export costume parts as 3D models or generated templates as printable files, such as PDF pattern sheets. |
| [**Print**](/patterns/printing) | Open the print dialog to print generated templates. |
| **Print To JPG** | Save generated templates as separate image files for sharing or printing at a print shop. |
| **Quit** | Close the application. |

In builds with the costume storage overhaul, **Save As** defaults to `.costume` and also offers legacy `.armor` saves. **Open** and **Merge** show both formats by default. See [Costume files](/interface/costume-files) for companion folders, published bundles, and legacy compatibility.

## Avatar menu

Use **Avatar** to edit measurements and poses, load a custom model, and save avatar or pose files.

| Command | What it does |
| --- | --- |
| [**Edit Avatar**](/avatar/creating-your-avatar) | Open avatar customization in Workbench Edit to set measurements, hair, colors, and local shape details before fitting costume parts. |
| [**Edit Pose**](/avatar/posing) | Enter pose editing mode. Select sphere joints and use **Translate** to move them, or select bones and use **Rotate** to turn them. |
| **Reset Avatar** | Restore the default pose and proportions, discarding avatar customizations. |
| **Reset Pose** | Restore the default pose, discarding pose changes. |
| **Change Pose** | Open a submenu of preset poses to apply to the avatar. |
| [**Open Avatar**](/avatar/saving-and-reusing-avatars) | Choose an existing avatar file from your computer. |
| [**Save Avatar**](/avatar/saving-and-reusing-avatars) | Save the current avatar to its existing file location. For an avatar you have never saved, this opens **Save As**. |
| [**Save As**](/avatar/saving-and-reusing-avatars) | Save the avatar with a new name or in a new location. |
| [**Custom Mesh → Import**](/avatar/custom-avatars) | Load an OBJ, STL, or FBX body model. Check its scale, skeleton, and attachment points before fitting parts. |
| **Export Avatar** | Export the avatar as a 3D model. Check the export dialog for supported file types. |
| **Save Pose** | Save the current pose to a file. |
| **Load Pose** | Open a pose file and apply it to the current avatar. |

A custom avatar with a skeleton created in [Mixamo](http://www.mixamo.com) can be posed and have appropriate attachment points created for it. For a model without a skeleton, use **Edit Pose** to position the attachment points.

## Edit menu

Use **Edit** to undo changes, manage selected objects, and work with pattern geometry.

| Command | What it does |
| --- | --- |
| **Undo** | Revert the last action. Most transformations, property changes, and geometry edits can be undone. |
| **Redo** | Reapply the last action you undid. |
| **Copy** | Copy selected objects to the clipboard so you can paste them elsewhere in the project. |
| **Paste** | Add copies of the objects on the clipboard to the scene. You can reposition them after pasting. |
| **Delete** | Remove selected objects. Use **Undo** to restore them if needed. |
| [**Translate**](/interface/translate-tool) | Move selected objects along the X, Y, and Z axes with the translation gizmo. |
| **Rotate** | Turn selected objects around any axis with the rotation gizmo. |
| [**Join/Cut**](/patterns/pattern-layout#change-how-pieces-connect) | Join pattern edges or cut a connection to separate pieces. See the edge-selection steps below. |
| **Scale** | Resize selected objects uniformly or independently along each axis. |
| [**Group Selection**](/parts/grouping-and-measuring) | Create a group from selected objects so you can manipulate the parts together in the scene hierarchy. |
| [**Unfold**](/patterns/pattern-layout) | Generate 2D patterns from the selected low-polygon mesh for arranging, editing, and printing. |
| **Join Adjacent Edges** | Join neighboring open edges within a specified tolerance to repair patterns. |
| [**Measure**](/interface/measurement-tool) | Measure a distance in the scene. Click one point to start, then a second point to finish. |

To join patterns with **Join/Cut**, select one edge and then a second edge. Use the arrow on the connecting join line to choose which pattern moves to the other. To separate pieces, click a connected edge.

## View menu

Use **View** to frame objects, change the camera angle, and customize the workspace appearance.

| Command | What it does |
| --- | --- |
| **Zoom All** | Frame all visible objects in the work area. |
| **Zoom Selected** | Center and zoom the view on selected objects. |
| **Set Camera** | Choose a predefined angle, such as Front, Back, Left, Right, Top, or Bottom. |
| **Theme** | Change the appearance of the application interface. |
| **Change Background** | Use a custom image as the work area background for reference or personalization. |
| **Reset Background** | Remove the custom background image and restore the default. |
| **Color Key Mode** | Display solid color-key materials for capturing images for compositing or masks. |

## Settings menu

Use **Settings** to change application preferences and the profile included with your costume files.

| Command | What it does |
| --- | --- |
| [**Preferences**](/interface/preferences) | Open the dialog for changing application settings. |
| **Edit Profile** | Edit the profile bundled with saved costumes. You can include your information, social media details, and logo as a watermark when sharing a costume. |

## Window menu

Use **Window** to recover panels without closing the costume.

| Command | What it does |
| --- | --- |
| **Workbench** | Show the shared Browse, Edit, and Inspect dock. Browse holds workspaces and context-specific attachments or patterns. |
| **Transforms** | Show numeric position, rotation, and scale controls. |
| **Costume**, **Workshop** | Show the corresponding work view. |
| **Command History**, **Debug Log** | Show the available history or diagnostic panel. |
| **Reset Window Layout** | Restore the default dock arrangement. |

Create 2D is replaced by the pattern view's **Create** menu. The former separate Workspaces and Property Grid controls are now in [Workbench](/interface/overview#use-workbench). Use [Browse → Patterns](/patterns/layers-and-groups) to organize drawings and **Edit Foam → Layers** for physical foam stacks.

## Help menu

Use **Help** to find documentation, updates, support, and community resources.

| Command | What it does |
| --- | --- |
| **Help Page** | Open the online documentation in your default browser. |
| **Keyboard Shortcuts** | Display the available keyboard shortcuts. |
| **Check For Updates** | Check whether a newer version is available and follow the prompts to download and install it. |
| **View Changelog** | Open the latest release notes for features, improvements, and fixes. |
| **Feature Request** | Open the window for suggesting features or improvements. |
| **Submit Bug** | Open the bug report window. Include details, screenshots, or steps to reproduce the issue. |
| **Tutorial Videos** | Open the video tutorial library in your default browser. |
| **Discussion Group** | Open the community discussion group in your default browser. |
| **Discord** | Open the official Discord server in your default browser. |
| **About** | Display the application version, licensing information, and credits. Keep your version number handy when contacting support. |

## Quick tips

<Tip>
- **Save often.** Press **Ctrl+S** after meaningful changes. Do not rely on a backup alone; save the working costume deliberately.
- **Import first, position second.** Use **File → Import** to bring in models, then fine-tune their placement with the [Transform Panel](/interface/transform-panel).
- **Check for updates.** Use **Help → Check For Updates**, then read the changelog to see what changed.
</Tip>

## Additional tools in this build

- [**File → Export → Costume to FBX...**](/parts/exporting-costumes#export-the-costume-to-fbx) exports the avatar and costume pieces as separate meshes.
- [**Tools → Environment Lighting**](/interface/lighting#author-and-check-indirect-lighting) opens lighting authoring and bake controls in the release build.
- [**Avatar → Custom Mesh → Import**](/avatar/custom-avatars) imports an OBJ, STL, or compatible FBX body. It is separate from File → Import.
