The Property Grid is Armorsmith Designer's precision editing panel. While you can drag objects around freely in the 3D Viewport, the Property Grid is where you type exact values — getting a chest plate to sit exactly 2 mm above the avatar surface, or confirming that a pair of shoulder pieces are scaled identically. It updates instantly whenever you select a different object.

## What the Property Grid Shows

When you select an object in the viewport, the Property Grid populates with that object's current state across four main categories:

- **Position** — X, Y, and Z coordinates that define where the object sits in the scene relative to the avatar's origin point.
- **Rotation** — X, Y, and Z rotation angles (in degrees) describing the object's orientation.
- **Scale** — X, Y, and Z scale multipliers. A value of `1.0` on all axes means the object is at its original imported size.
- **Material** — Surface properties such as colour and any visual display settings that affect how the part appears in the viewport.

When nothing is selected, the Property Grid is empty. Click any object in the viewport to populate it.

## Selecting an Object to Populate the Property Grid

<Steps>
  <Step title="Click the object in the 3D Viewport">
    Left-click directly on any mesh — your avatar or any attached costume part — in the viewport. A selection highlight will appear around the object.
  </Step>
  <Step title="Review the Property Grid">
    The panel updates immediately to show the selected object's position, rotation, scale, and material values.
  </Step>
  <Step title="Click empty space to deselect">
    Left-clicking on an empty area of the viewport deselects the current object and clears the Property Grid.
  </Step>
</Steps>

## Editing a Value

<Steps>
  <Step title="Locate the field you want to change">
    Find the property — for example, **Position → Y** — in the Property Grid.
  </Step>
  <Step title="Click the value field">
    Single-click the numeric field to put it into edit mode. The current value will be highlighted.
  </Step>
  <Step title="Type the new value">
    Enter your new number. Values use whichever unit system you have configured in Preferences (mm, cm, or inches).
  </Step>
  <Step title="Confirm the change">
    Press **Enter** to apply the value. The object in the viewport moves or updates immediately. Press **Escape** to cancel the edit and revert to the previous value.
  </Step>
</Steps>

## Showing and Hiding the Property Grid

You can toggle the Property Grid panel at any time without affecting your project:

1. Click **Windows** in the Menu Bar.
2. Click **Property Grid** in the dropdown.

When the panel is visible, a checkmark appears next to the menu item. Clicking it again hides the panel. The panel remembers its docked position between sessions.

<Warning>
  **Property Grid missing after an update?** A known issue in certain versions of Armorsmith Designer causes the Property Grid to be hidden by default following an update — even if it was visible before. If you open a project and can't find the panel anywhere on screen, go to **Windows → Property Grid** to restore it. This is the most common reason new or returning users find the panel missing and is not a sign that anything is wrong with your project file.
</Warning>

<Tip>
  If you need to apply the same property value to multiple objects — for example, setting every piece to the same Y position to align them on a shared baseline — select each object in turn and type the value manually into the Property Grid. There is no multi-select edit, so working through them one at a time is the reliable approach.
</Tip>
