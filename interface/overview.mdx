<Info>
These instructions describe the upcoming **Armorsmith Designer 2.1.1.0** interface. The public 2.1.0.10 release can show different panels and labels.
</Info>

Use **Costume** to fit armor to the avatar and **Workshop** to work with a model and its flat patterns. **Workbench** holds the browsing, editing, and inspection controls beside those views.

## Choose a view

| Area | Use it for |
| --- | --- |
| **Costume** | Place and fit attached parts around the avatar. Inspect the fit from several angles. |
| **Workshop** | Edit a workspace's model, draw outlines, and arrange patterns on paper. |
| **Menu bar** | Open, save, import, export, change preferences, and show panels. See the [menu reference](/interface/menu-bar). |

The model and pattern views serve different tasks. Moving a paper template does not reposition its fitted attachment on the avatar.

## Use Workbench

Choose **Window → Workbench** if the dock is not visible.

| Tab | What it shows |
| --- | --- |
| **Browse** | [Workspaces](/interface/workspaces-panel) and their content. Costume offers attachment browsing; Workshop offers drawing layers and patterns. |
| **Edit** | Controls for the active tool, such as avatar customization, FFD, Fit Check, Edit Shape, or Edit Foam. |
| **Inspect** | [Properties](/interface/property-grid) of the selected object or workspace. |

Activate a tool from its normal menu or viewport button to open its editing controls. Use **Done** to finish a tool when that button is shown. Tools with **Apply** and **Cancel** use those controls to accept or abandon the proposed operation. Changing the visible Workbench tab alone is not a substitute for finishing a tool.

Workbench moves as one dock. Browse, Edit, and Inspect are pages inside it, rather than separate docks to rearrange individually.

## Enter precise transforms

The separate **Transforms** panel contains position, rotation, and scale. Use it for exact values and use the viewport gizmos for interactive adjustment. See [Transform Panel](/interface/transform-panel).

## Start a costume

1. [Create and save a costume](/getting-started/first-costume).
2. Choose **Avatar → Edit Avatar** to enter body measurements in Workbench Edit.
3. Import a model and select it under **Browse → Workspaces**.
4. Attach it to the avatar, then position and check the fit.
5. Open Workshop when you are ready to work on its patterns.

For camera controls, see [viewport navigation](/interface/viewport-navigation). If the panel arrangement becomes difficult to use, choose **Window → Reset Window Layout**.
