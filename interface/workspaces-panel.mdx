<Info>
These instructions are for **Armorsmith Designer 2.1.1.0**. Earlier versions, including 2.1.0.10, can show different panels and labels.
</Info>

A **workspace** holds a model and its pattern work. An **attachment** places that workspace's geometry on the avatar. Keep this distinction in mind when deleting or fitting a part.

Open **Window → Workbench**, then select **Browse → Workspaces**.

## Find a workspace

![Workspaces grid with search, selected workspace details, and Attach Another Copy.](/images/workbench-overview-2110.png)

*Select a workspace to see its details and attachment action.*


Choose **Grid** for thumbnails or **Rows** for a compact list. Use **Search workspaces** to find a name and the group filter to narrow the list. Select a workspace to see its preview and available actions.

Clear the search and choose **All workspaces** if you cannot find an imported item. Selecting a workspace does not automatically attach it to the avatar.

## Import or create

- **Import Model** opens the [model import workflow](/parts/importing-models).
- **New Workspace** creates a blank workspace for drafting your own patterns.

Keep any original model files and textures available, particularly when using [linked sources](/parts/linked-files).

## Manage names and groups

Right-click a workspace for actions such as **Rename…**, **Export Model…**, and **Manage Group…**. Group related sources when they belong to one assembly, such as a helmet and its separate cheek pieces. Use the group filter to find them together.

**Attach Group To Costume** places an assembly as a group. Inspect the result before fitting individual regions; grouping does not automatically make an assembly fit the wearer.

## Attach a workspace

1. Select a workspace containing geometry that can be attached.
2. Click **Attach To Costume**. If it already has an attachment, the button can read **Attach Another Copy**.
3. Move over the avatar and click the intended attachment point.
4. Use Translate, Rotate, and Scale to fit the part.

An empty drafting workspace may need [foam geometry](/foam-preview/thickness-and-forming#attach-and-refresh-the-costume) before it can be attached. Follow [Attachments](/parts/attaching-parts) for fitting, mirroring, and managing fitted copies.

## Browse attachments or patterns

In Costume, use **Browse → Attachments** to find fitted parts by body slot. **Reveal Workspace** takes you back to a selected attachment's source workspace.

In Workshop, use **Browse → Patterns** to [organize drawing layers and groups](/patterns/layers-and-groups). Physical foam stacks are edited through **Edit Foam → Layers**, not a separate Browse Foam Layers tab.

## Delete a workspace safely

Deleting a workspace also removes attachments that depend on it. If you only want to remove a fitted copy, use **Delete Attachment** in attachment browsing instead. Save a copy of a useful costume before removing source workspaces.

For backups, keep an editable `.costume` file and its companion folder together. Use [Publish Costume](/interface/costume-files#publish-one-file-for-sharing) for a single-file handoff.
