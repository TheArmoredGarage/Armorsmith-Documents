If something doesn't look or behave the way you expect in Armorsmith Designer, you're likely running into one of a handful of well-known issues. Most problems can be resolved in just a few steps without reinstalling. Work through the relevant section below and reach out if you need further help.

<Accordion title="Black screen after creating my avatar">
  A black screen immediately after avatar creation is almost always caused by an invalid or out-of-range body measurement entered during setup.

  To fix it:
  1. Go to **Avatar → Reset Avatar** in the menu bar.
  2. Restart Armorsmith Designer.
  3. Re-enter your measurements carefully, making sure all values are within realistic ranges.
</Accordion>

<Accordion title="The Property Grid is missing">
  A bug introduced in a recent update caused the Property Grid panel to be hidden for some users, particularly those launching Armorsmith Designer for the first time after an update.

  To restore it:
  1. Go to **Windows** in the menu bar.
  2. Click **Property Grid** to toggle it back on.

  The panel should reappear immediately in its default position.
</Accordion>

<Accordion title="The program crashed">
  If Armorsmith Designer crashes, a prompt will usually appear asking you to submit crash logs. Sending those logs helps the developer identify and fix the underlying problem — please submit them when asked.

  If no prompt appears:
  - Locate any crash log files saved to your installation folder.
  - Email them directly to [TheArmoredGarage@gmail.com](mailto:TheArmoredGarage@gmail.com) with a short description of what you were doing when the crash occurred.
</Accordion>

<Accordion title="Parts look the wrong scale — too big or too small">
  Scale problems on costume parts are usually caused by a mismatch between the unit system used for your avatar measurements and the unit system set in the application preferences.

  To fix it:
  1. Open **Preferences** and check whether the unit system is set to **Imperial** (inches) or **Metric** (centimeters).
  2. Confirm that your avatar measurements were entered in the same unit system.
  3. If there is a mismatch, go to **Avatar → Reset Avatar**, switch to the correct unit system, and re-enter your measurements.
</Accordion>

<Accordion title="I can't find a menu item">
  If a menu item described in a tutorial or guide doesn't appear in your installation, you may be running an older version of Armorsmith Designer. New features and menu options are added with each update.

  To get the latest version, go to **Help → Check For Updates** and follow the on-screen prompts. See the [Updates & Licensing](/troubleshooting/updates-and-licensing) page for more details.
</Accordion>

<Note>
  For issues not covered here, contact support at [TheArmoredGarage@gmail.com](mailto:TheArmoredGarage@gmail.com). Include your operating system version, a description of the problem, and any relevant screenshots or crash logs.
</Note>
