Open **Avatar → Edit Avatar** to customize your avatar. **Full Body** contains hair and color options. **Details** contains local shape controls for the head and torso. Changes appear immediately in the viewport.

Set the base body and [measurements](/avatar/body-measurements) before making fine appearance adjustments.

## Hair and colors

| Full Body setting | What it changes |
| --- | --- |
| **Hair** | The selected hairstyle. Choose **None** for an unobstructed view of the head. |
| **Facial Hair** | The selected facial hair style. Available choices depend on the base avatar. |
| **Hair Color** | Hair and facial hair color. |
| **Skin Color** | Skin tone. |
| **Eye Color** | Eye color. |
| **Underwear Color** | Underwear color. |
| **Enable Fullbody Color** | Displays the avatar with a full-body color override. |

Colors change the display material. Hairstyles add visible geometry, so check the intended hairstyle when fitting helmets or headpieces. Hair does not automatically add clearance to a costume part.

## Head details

Expand **Details → Head** to adjust these features:

| Control | What it changes |
| --- | --- |
| **Eye Size** | The local size of the eye regions. |
| **Eye Height** | Their vertical position. |
| **Eye Width** | Their spacing across the face. |
| **Nose Width** | The nose from side to side. |
| **Nose Length** | The vertical length of the nose. |
| **Nose Depth** | How far the nose projects from the face. |
| **Nose Height** | Its vertical position on the face. |
| **Mouth Size** | The local size of the mouth region. |
| **Mouth Height** | Its vertical position. |
| **Ear Size** | The local size of the ear regions. |
| **Ear Height** | Their vertical position. |

Make one adjustment at a time. Compare the front view for width and spacing, and a side view for projection. Match overall head dimensions before refining features with these sliders.

## Torso details

Expand **Details → Torso** for **Breast Size**, **Breast Height**, **Breast Projection**, and **Butt Size**.

The breast controls work independently. Their midpoint preserves the base mesh's original size, height, or projection for that control. Read [Chest and breast shape](/avatar/chest-and-breast-shape) for the adjustment order and examples.

**Butt Size** adjusts the local seat region. Check the side view and the transition into the hips and thighs, rather than judging it only from behind.

<Note>
Face and torso detail sliders change avatar geometry. Recheck nearby costume parts after adjusting them. They are different from color settings, and their positions are not measured lengths, circumferences, or bra sizes.
</Note>

## Use appearance changes while fitting

Temporarily hide hair or attached parts when they obscure the body. In **Full Body**, use **Show Costume** to toggle attached costume pieces while editing.

After adjusting geometry, show the costume again and inspect clearance. Check a helmet near the nose and ears, or a breastplate near the chest. Use [Fit Checker](/parts/fit-checker) as an additional view of the gap between a part and the avatar.

## Save a reusable appearance

Choose **Avatar → Save Avatar**, or **Avatar → Save As** to make another `.avatar` file. Use separate files for different wearers or clothing setups.

**Avatar → Reset Avatar** restores measurements and appearance settings. Save a copy before using it; it is broader than resetting one measurement. See [Saving and reusing avatars](/avatar/saving-and-reusing-avatars).
