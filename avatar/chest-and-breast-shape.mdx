Measure while wearing the supportive garment or base layer intended for the costume. Record **Underbust** around the ribcage beneath the breasts and **Full Bust** around the fullest area. Keep the tape level without compression.

## Avatar 4 workflow

Open **Avatar → Edit Avatar**, then use **Circumferences → Breast Shape** in Workbench Edit. These controls are available for an adult female Avatar 4 with the required body shapes.

1. Fit standing height and larger torso proportions first.
2. Set Underbust to match the ribcage and check the front and profile views.
3. Set Full Bust to the supported measurement. The difference between Full Bust and Underbust controls approximate cup and breast fullness.
4. Choose **Cup System** and use **Cup Size** as an approximate starting preset if useful.
5. Refine placement and silhouette with the controls below.
6. Recheck the readings, show the fitted costume, and [check clearance](/parts/fit-checker).

Changing Underbust preserves the bust-minus-underbust difference, so recheck Full Bust after a torso-size edit. Full Bust cannot be lower than Underbust. Measurement locks can constrain a requested edit; read any error and use Undo rather than repeatedly forcing conflicting values.

## Refine the silhouette

| Control | Use it for |
| --- | --- |
| **Cup System** | Choose US / Canada or UK labels for approximate presets. |
| **Cup Size** | Start from an approximate cup difference at the current torso size. |
| **Spacing** | Bring the breasts closer together or farther apart. |
| **Vertical Position** | Adjust height on the torso without using cup size as a position control. |
| **Firmness** | Blend the authored soft-to-firm appearance. It is not a measured tissue property. |
| **Outer Fullness** | Refine the outer breast root toward the side of the chest. |

Cup letters vary by brand and sizing system. The preset does not guarantee bra fit or a final breastplate shape. Compare the silhouette with the support intended for the costume, and avoid shrinking an accurate ribcage merely to reduce local fullness. Adjust the armor part when appropriate.

## Older built-in avatars

Older bodies use **Details → Torso** with independent Breast Size, Breast Height, and Breast Projection controls. Their midpoint preserves the base shape for that control; the sliders are not tape readings or cup sizes.

Older files using the combined Breast Size slider are converted into independent settings to retain the saved shape. Keep the converted values if that is the shape you want. Moving every slider to its midpoint changes it back toward the original base mesh.

Save a copy before refining an older setup. See [body measurements](/avatar/body-measurements), [avatar troubleshooting](/avatar/avatar-troubleshooting), and [saving avatars](/avatar/saving-and-reusing-avatars).
