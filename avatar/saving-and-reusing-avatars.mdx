Save an avatar once its measurements and shape are ready. Reuse that body setup for another costume or keep different versions for different wearers and base layers.

## Save your first avatar

1. Finish your [measurements](/avatar/body-measurements) and [shape adjustments](/avatar/customizing-appearance).
2. Choose **Avatar → Save As**.
3. Choose a folder and a descriptive name, such as `Alex-bodysuit-2026-10.avatar`.
4. Save the file.

**Avatar → Save Avatar** saves to the current avatar file. If it has no saved location yet, it opens the save dialog.

Use **Avatar → Save As** for a new version without replacing the previous file. Record the units, measurements, and clothing setup in notes beside it.

## Open a saved avatar

Choose **Avatar → Open Avatar** and select the `.avatar` file. Check the body type, height, measurements, and shape before fitting new parts.

If you open a different body setup while working on a costume, inspect attached parts again. A part fitted to one wearer can need a different position, scale, or shape for another.

## Choose the right file

| File or command | Use it for |
| --- | --- |
| `.avatar` through **Avatar → Save Avatar / Save As** | A reusable avatar setup, including measurements and appearance/shape settings. |
| Costume project through **File → Save / Save As** | Your ongoing costume work. Save it alongside the avatar to keep the fitted project. |
| Pose file through **Avatar → Save Pose / Load Pose** | Reusing a stance or a clearance-check pose. |
| OBJ or STL through **Avatar → Export Avatar** | A 3D mesh for another application. It is different from the editable `.avatar` setup. |

For movement checks, read [Posing your avatar](/avatar/posing). For imported scans or models, read [Custom avatars](/avatar/custom-avatars).

## Keep fitting setups separate

Save a separate avatar when the body or intended clothing changes. For example:

- A closely fitted bodysuit and a thicker padded undersuit.
- The same wearer at a later measurement date.
- Different people using the same costume model.

Choose the base **Gender** before entering new measurements. Changing it resets the selected avatar to its baseline, so save the existing setup first.

## Before resetting or experimenting

Create a copy with **Avatar → Save As** before a large shape change or **Avatar → Reset Avatar**. A whole-avatar reset restores measurements and appearance settings; it is broader than a pose reset or a field's reset button.

When opening an avatar made with the old combined breast slider, its shape is converted to the independent controls. Read [Chest and breast shape](/avatar/chest-and-breast-shape#open-an-avatar-made-with-the-older-slider) before moving those sliders to their midpoints.

## Keep custom model files with your setup

A custom avatar can depend on an external source model. Keep the OBJ, STL, or FBX and associated texture files available when moving work to another computer. Retain the original import so you can reload it if a path changes.

If a setup opens with unexpected proportions or missing geometry, see [Avatar troubleshooting](/avatar/avatar-troubleshooting).
