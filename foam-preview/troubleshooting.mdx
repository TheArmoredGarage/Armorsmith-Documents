<Info>
These instructions are for **Armorsmith Designer 2.1.1.0**. Earlier versions, including 2.1.0.10, can show different panels and labels.
</Info>

## I cannot find the old foam toolbar

In the 2.1.1.0 interface, select an outline and use **Edit Shape** or **Edit Foam**. Their controls appear in **Workbench → Edit**. Physical stacks are in **Edit Foam → Layers**; there is no separate Browse Foam Layers tab in this workflow.

The public 2.1.0.10 release has different controls. Check your version under Help → About before following these steps.

## A new outline has no solid preview

Creating an outline makes drawing geometry. Close it, make sure it encloses an area without crossing itself, then right-click it and choose **Promote To Foam Pattern**. Enable **Foam** and make sure the pattern and its parent drawing layers are visible.

For a layer member, its base must also have a valid preview. Read the editor's feedback for invalid thickness, radius, edge depth, or outline geometry. Use the viewport's fit/zoom controls if the preview is offscreen.

## A piece disappears after editing its outline

Opening or breaking a closed outline can remove solid eligibility. Reclose it before judging the foam preview. A raised pattern can also stop fitting inside the base after an outline or scale edit. Undo the edit or bring its whole boundary back inside.

## The form bends the wrong way

Select the base and use **Advanced Forming → Reverse Forming Direction**. Check the front and side views. A layer member inherits the base's form; use **Edit Base Form** to edit that shared surface.

## A spherical form is invalid

Use a larger Radius for a gentler dome and stay within the valid range shown for the outline and thickness. Recheck the radius after resizing the outline. A geometric spherical preview is not a prediction of foam stretching; test a physical sample.

## The preview is angular or changes detail during a drag

Adjust **Triangle Budget** for the selected pattern. It covers the complete 3D solid, not the flat cutting outline. Curvature and rounded edges share that detail budget. Very complex outlines can still fail with too small a budget.

Interactive sliders or movement can temporarily reduce detail. Release the control and inspect the settled result. A missing final mesh or geometry error is different from this temporary preview.

## A pattern is skipped when added to a layer

Read the skipped-pattern feedback. Use a closed, valid, editable outline in the same workspace. It must fit completely inside the base; corners inside the base are not enough if a segment crosses a concave cutout. A pattern that already owns a stack cannot be nested as a raised member.

Select the destination layer before **Add Selected**. **Choose Patterns…** lists eligible outlines when viewport selection is awkward.

## Reordering did not change a layer's height

That is expected. **Move Up** and **Move Down** reorder the list. Use **Height Above Base** for physical height, measured from the base's outer surface to the layer underside. A first layer glued directly to the base uses 0 mm.

A new layer starts above the previous layer once; later thickness or ordering edits do not automatically restack the assembly. Check each layer's height deliberately.

## Moving a pattern changes the wrong thing

Check the selected target. The base moves the whole stack. A raised member uses local X/Y Translate and local Z Rotate in the 3D view. The 2D view arranges paper templates independently.

Use Escape during an unfinished drag to restore its starting placement. Double-click a pattern row to open that pattern's settings.

## The editor shows mixed values

Several selected patterns have different settings. Enter a shared value only if you intend to change all selected targets. For mixed Edge Finish units, choose common Units before entering Depth.

## Edge depth becomes invalid after a thickness change

A fixed millimetre depth can exceed the new thickness. Reduce Depth, increase Thickness, or choose a suitable percentage. Inspect every piece after a batch edit; thinner trim may need a different depth from the base.

## I removed the wrong pattern

Use **Edit → Undo**. **Remove From Layer** preserves a member in the workspace. **Delete Layer…** deletes the layer and its patterns. Detach members you want to keep before deleting a layer.

## Costume geometry does not match Workshop

Use **Refresh Costume Meshes** after editing the foam patterns. Check that the base is enabled for **Attach As Part** and that the workspace has been attached where intended. Refresh regenerates geometry and replaces mesh edits, so save a copy before updating a further-edited attachment.

Recheck placement and appearance, save, and reopen a test copy. If it still differs, report the build version, affected costume, and the smallest sequence that reproduces the result.

## Printable Details is missing

The control can appear in the editor, but decorative hardware placement is not verified by this guide. Foam build sheets are not part of this supported route. Use the [layered bracer tutorial](/foam-preview/tutorial-layered-bracer) and ordinary pattern printing, with construction notes kept separately.
