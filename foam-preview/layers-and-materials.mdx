A foam stack starts with one base pattern. Add layers above it, then put smaller patterns into each layer. One layer can contain several circles, strips, or other detail shapes.

All patterns follow the base's forming and 3D placement. Each pattern keeps its own outline, thickness, edge finish, and material.

If the base belongs to a [glued assembly](/foam-preview/instances-and-gluing), its layers follow that piece's relaxed surface. Layer placement stays local to its own base. **Form**, **Place**, and **Move foam** affect the shared assembly, while layer materials and thickness remain individual settings.

## Create the stack

1. Select a closed foam pattern with a working **Foam** preview.
2. Click **Layers** to open the **Foam layers** panel.
3. Click **Use selected base**.
4. Click **Add layer**.
5. Click the new layer's row in the panel to make it the destination.
6. Select one or more closed foam patterns in the pattern view.
7. Click **Add selected patterns**.

The tool uses their relative placement as an initial assembled position where possible. If a pattern is outside the base, it tries centering the assembled piece. Its cutting-sheet position stays unchanged. It rejects a pattern that still cannot fit. Resize or reshape that pattern and try again.

A pattern that already contains its own foam layers cannot be nested into another stack in this preview.

<Tip>
Single-click a row to choose a destination or material target without replacing your viewport selection. Double-click a row to select that pattern or layer in the application.
</Tip>

## Move a raised pattern

The 2D cutting-sheet layout and the assembled layer placement are saved separately. Translate or rotate the templates in 2D to arrange them for printing without moving the raised pieces in 3D. Use **Move on surface** to change the assembly without moving the paper templates. Editing an outline or changing its scale changes the actual piece, so check that it still fits its base.

Click **Move on surface**, then click and drag a raised foam pattern in the 3D view. The pattern moves across the base's flat coordinates and follows the formed surface as you drag.

Use **Move foam** on the toolbar to move the whole base stack in the left-hand 3D preview. Clicking a layer member or rivet in that mode selects its base. Use **Move on surface** to slide a member within the stack instead. For several independent bases, see [Arrange separate plates](/foam-preview/thickness-and-forming#arrange-separate-plates-such-as-a-set-of-abs).

Its entire outline must stay within the base outline. Movement that would cross the boundary is rejected, including movement across an indentation in a concave base.

Release to keep the move as one undoable action. Press **Escape** during an unfinished drag to restore the starting position. Click **Finish moving** to leave the tool.

The boundary is the stack's base outline. Upper patterns do not need to sit directly above another small pattern in the preceding layer.

## Read the composition

The tree shows the base, each layer, and the patterns within it. Pattern rows show thickness and material. Layer rows show the number of patterns and the height above the base surface.

- Use the row checkboxes to show or hide pieces while inspecting the composition.
- **Raise layer** and **Lower layer** change layer order.
- **Set layer gap** adds space above the preceding layer.
- **Remove row** removes the selected pattern or layer, with undo. Removing a layer removes its children from the composition too.

Each layer starts above the tallest pattern in every lower layer, plus the layer gaps. For example, a layer containing both 2 mm and 4 mm patterns contributes 4 mm to the next layer's elevation. This keeps each layer at one shared height; it does not nest upper pieces into the gaps between lower details.

For pieces glued directly onto the base, leave the first **Layer gap** at **0 mm**. Its underside already rests on the base's top surface; do not add the base thickness again. The initial 3D camera shows the raised side. Orbit the view to inspect the back or the side profile.

Hiding a layer changes visibility, rather than the physical stack height. Remove or reorder a layer when you want the composition itself to change.

## Set one pattern's material

1. Click the pattern row in **Foam layers**, including the base row if needed.
2. Choose a material from the list, or choose **Custom color...**.
3. Click **Set pattern material**.
4. If you chose a custom color, select it in the color picker.

The selected pattern changes independently. Its attached hardware inherits the same material.

## Set the whole layer's material

Choose a layer row, select a material, then click **Apply material to whole layer**. This updates every pattern currently in the layer and sets the default for patterns added later.

The patterns receive independent material copies. You can override one pattern afterward with **Set pattern material** without changing its neighbors. Undo restores each pattern's previous assignment.

Materials affect the 3D appearance. They do not change the paper cut outlines, thickness, or forming.
