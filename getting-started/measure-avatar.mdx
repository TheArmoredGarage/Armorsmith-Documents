Create a built-in avatar for the person who will wear the costume. You will enter measured dimensions, inspect the silhouette, and save an `.avatar` file for reuse.

## Before you start

Open a [saved costume](/getting-started/first-costume). Have a flexible tape measure, a measurement record, and someone to help with hard-to-reach readings. Measure while wearing the base layer and supportive garment intended for the costume.

Record standing height, shoulder width, sleeve/arm segments, inseam/leg segments, and the relevant body circumferences. Use the application's highlighted guides to identify endpoints; a clothing measurement with different endpoints is not interchangeable.

## 1. Choose a starting body

1. Choose **Avatar → Edit Avatar**.
2. On **Avatar**, choose **Male** or **Female** in **Base avatar**.
3. Adjust **Age** and **Body build** to a useful starting silhouette. **Body mass** and **Muscularity** are relative shape controls, not weight measurements.
4. Enter **Standing height** with units and press **Enter**. Use your own reading; `175 cm` is only an entry-format example.

**Check:** The body changes in the Costume viewport. Set the starting shape and height before fine-tuning individual dimensions.

## 2. Enter lengths

1. Open **Measurements** and find the relevant body region.
2. Hover over a field to identify its guide. Compare the endpoints with your measurement record.
3. Enter the measured value and press **Enter**.
4. Set totals such as **Sleeve** and **Inseam** before refining **Shoulder to elbow**, **Elbow to wrist**, **Crotch to knee**, and **Knee to ankle** where available.
5. Inspect joint positions and recheck the total after changing a segment.

See [body measurements](/avatar/body-measurements) for the field names and relationships. Available rows depend on the loaded body.

## 3. Match circumferences and local shape

1. Open **Circumferences**. Enter the waist, hip, chest, arm, and leg readings you need at the levels shown by the guides.
2. Compare front and side views. Adjust **Shape** when a region needs a different balance of width and depth.
3. Use the lock beside a verified measurement if you need to preserve it while changing related dimensions. Unlock it before intentionally changing that field.
4. Use **Head** for head dimensions and **Hands** for the available hand/finger measurements.

For breast shape, follow the [chest guide](/avatar/chest-and-breast-shape). A cup preset is a starting shape; check the actual silhouette and tape measurements.

## 4. Check and save

1. Inspect the front, side, and back. Recheck any dimensions affected by larger shape changes.
2. Read any constraint error in the panel. Review locks and related values before trying again; use **Edit → Undo** to reverse an unwanted edit.
3. Choose **Avatar → Save As** and save `My fitting avatar.avatar`.
4. Choose **File → Save** to save the costume as well.

**Result:** You have a reusable measured avatar. It is a fitting reference, so verify important openings with a physical mock-up before cutting final material.

Next, [import a costume model](/getting-started/import-first-model). If the body still looks wrong, use [avatar troubleshooting](/avatar/avatar-troubleshooting).
