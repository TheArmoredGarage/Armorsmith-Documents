Print a test page at the intended physical size, verify it with a ruler, then print and assemble the remaining pattern pages.

## Before you start

Use the full version of Designer with a [reviewed pattern layout](/getting-started/first-pattern-layout). Have paper, a printer, a ruler, and tape ready. Save the costume. Printing uses the currently selected workspace, so select the one whose patterns you intend to print.

## 1. Match the layout to the paper

1. Open **Workshop** and inspect the 2D pattern pages.
2. Select the workspace and expand **Print** in the **Property Grid**.
3. Choose **Paper Size** to match the paper in the printer. Check **Side Margins** and **Top/Bottom Margins** against the printer's printable area.
4. Arrange or pack the pieces again if the paper or margins changed. Inspect the resulting page boundaries.

## 2. Make the output readable

1. Expand the workspace's **Display** properties.
2. Enable **Show Page Numbers** and **Show Registration Marks** for a multi-page layout.
3. Enable **Show Edge Ids**, **Show Edge Angles**, **Draw Solid Folds**, and **Show Tabs** only as needed for the construction method.
4. Check that lines, labels, and matching edges are readable before printing. Turn off textures if they obscure the construction details.

**Check:** You can identify how the pieces connect. Registration marks help line up corresponding pattern edges, and edge labels identify matching connections.

## 3. Print and measure one page

1. Activate **Measure** above the pattern view. Click two recognizable endpoints on one piece and note the straight-line distance.
2. Click the printer button above that view; its tooltip is **Print the current patterns**. You can also use **File → Print**.
3. In the Windows print dialog, choose the printer and matching paper. Set a page range containing the feature you measured so you print only the test sheet or sheets.
4. If the printer driver offers scaling, choose **100%** or **Actual Size** and turn off **Fit to Page**. The exact driver labels vary.
5. Print, then measure between the same endpoints on paper. For example, an on-screen 100 mm span should measure 100 mm on the print.

If **Print Mismatch** warns that paper sizes differ and clipping may occur, choose **No**, correct the workspace and printer paper sizes, and try again. Do not compensate by resizing an accurately fitted model.

## 4. Print the set and assemble a test

1. Once the test dimension is correct, reopen printing and print the required page range.
2. Sort the sheets by page number and align any pattern lines that continue across page boundaries. Tape the sheets without stretching or overlapping the printed geometry. Use registration marks and matching edge labels when joining the pattern pieces.
3. Cut and assemble a paper or inexpensive mock-up using the displayed matching edges, tabs, and folds appropriate to the pattern.
4. Check it against the intended body area or avatar measurements before cutting final material.

**Result:** You have a physically checked test template. If the mock-up needs a shape change, adjust the fit or pattern, save, and repeat the scale check after reprinting.

If the output is clipped, review paper size and margins. If every dimension is proportionally wrong, review driver scaling first. See [printing reference](/patterns/printing), or continue to [saving, sharing, and exporting](/getting-started/share-and-export).
