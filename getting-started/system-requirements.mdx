Before you install Armorsmith Designer, confirm that your PC meets the requirements below. The application is designed to run on most modern Windows computers — if your machine can handle current Windows software and has a GPU with DirectX 11 support, you are almost certainly good to go.

## Minimum system requirements

| Component | Minimum requirement |
|-----------|-------------------|
| **Operating System** | Windows 10 or higher (64-bit) |
| **CPU** | 64-bit processor |
| **GPU** | DirectX 11 capable graphics card |
| **RAM** | 2 GB |

<Note>
  Armorsmith Designer is a Windows-only application. macOS and Linux are not supported at this time. If you are on a Mac and would like to express interest in a future macOS version, send a note to [TheArmoredGarage@gmail.com](mailto:TheArmoredGarage@gmail.com).
</Note>

<Tip>
  While 2 GB of RAM is the minimum, working with large or complex 3D model files will be smoother with 4 GB or more. If you notice slowdowns when importing detailed FBX or OBJ files, freeing up system memory by closing background applications can help.
</Tip>

## Supported 3D model file formats

Armorsmith Designer can import and work with four common 3D file formats used in the cosplay and 3D modeling communities:

| Format | Extension | Description |
|--------|-----------|-------------|
| **Wavefront OBJ** | `.obj` | A widely supported text-based 3D mesh format exported by most 3D modeling applications, including Blender, Maya, and ZBrush. |
| **Stereolithography** | `.stl` | The standard format for 3D printing. STL files contain only mesh geometry, making them lightweight and easy to source from sites like Thingiverse or Printables. |
| **Autodesk FBX** | `.fbx` | A full-featured format that supports meshes, materials, and scene data. Commonly used for game assets and character models. |
| **Pepakura Designer** | `.pdo` | The native format for Pepakura Designer paper-craft files. Armorsmith Designer can import PDO files directly, so you do not need Pepakura Designer installed to use them. |

<Note>
  Armorsmith Designer is a standalone application. You do **not** need Pepakura Designer or any other third-party software installed on your PC to open PDO files or to use any feature of Armorsmith Designer.
</Note>
